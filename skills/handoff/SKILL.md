# 次のセッションへ渡す

入力は目的、進捗、判断、未完了、branch/worktree、検証証拠、active agent。

1. [引き継ぎガイド](../../context/handoff.md)を読み、Git実体と記録先を確認する。参照はこのSkillの実体ディレクトリ(symlink先)から解決する。
2. 目的と完了条件、現在地、判断と根拠、未完了、次の1〜3手を書く。既存のplan/Issue/ADRは参照にする。
3. 観測時刻、HEAD/dirty変更、branch/worktree、検証の対象状態と結果、agentの担当と最終観測、承認済み作用の範囲を残す。
4. 同じタスクの文書を更新し、並列担当は別ファイルにする。秘密と会話全文は含めない。

出力は引き継ぎ文書のpathと次の行動。完了条件は、新しいセッションが目的・次の一手・状態の再確認先を特定できること。

再開時は記録を読んだ後、Git/PR/Issue/agentの実際の状態を確認する。過去の検証や稼働記録を現在の状態とみなさない。恒久ルールの自動追加、別セッションの二重起動、外部送信は行わない。
